About RasterLab

RasterLab provides standard spatial dataset normalization using numerical transformation. Converting imagery bands to float range $[0, 1]$ removes gain discrepancies while preserving original spatial georeferencing, affine transforms, and Coordinate Reference Systems (CRS).
